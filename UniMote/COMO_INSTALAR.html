📺 UniMote — Guia de Instalação

Como instalar e testar no seu celular Android

🚀 MÉTODO 1 — Instalar direto pelo celular (mais fácil)

1

Abra o arquivo index.html no seu celular Android

2

Toque no menu do Chrome (⋮) → "Adicionar à tela inicial"

3

Confirme e o UniMote aparecerá como app na sua tela!

✅ Funciona como app nativo, abre em tela cheia, sem barra do browser.

🌐 MÉTODO 2 — Hospedar no GitHub Pages (grátis)

1

Crie conta em github.com (grátis)

2

Crie repositório público chamado unimote

3

Faça upload de todos os arquivos desta pasta

4

Vá em Settings → Pages → Source: main → Save

5

Acesse: https://SEU_USUARIO.github.io/unimote

Qualquer pessoa com o link pode instalar no celular!

📦 MÉTODO 3 — Gerar APK com Capacitor (intermediário)

npm install -g @capacitor/cli
npm install @capacitor/core @capacitor/android
npx cap init UniMote com.max9342.unimote
npx cap add android
# Copiar index.html para /public/
npx cap sync
npx cap open android
# No Android Studio: Build → Generate APK

Requer: Node.js + Android Studio instalados no computador.

🏪 MÉTODO 4 — Publicar na Play Store

1

Gere o APK pelo Método 3

2

Crie conta no Google Play Console (taxa única US$25)

3

Crie um novo app → faça upload do APK/AAB

4

Preencha: nome, descrição, screenshots, classificação

5

Adicione política de privacidade (obrigatório)

6

Envie para revisão (1-7 dias)
